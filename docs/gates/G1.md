# G1 exit evidence — Types, catalog, scalar oracle, query DSL slice

## Summary

A DER Semantic Query DSL document can be sent over HTTP, bound to the catalog, executed
over a `.derc` partition, and returned as a typed response with provenance.

## Deliverables

- `dap-core` typed value model (bool/i32/i64/f64/decimal128/utf8/uid/period/timestamp) with
  IEEE total ordering, DHIS2 UID validation, period parsing + bucketing (ISO weeks pass
  Wikipedia fixtures), schema definitions, `Provenance`.
- `dap-catalog` versioned registry with datasets, data elements, category combos / option
  combos, org units with hierarchy expansion, programs, program stages, program indicators,
  indicators, and a lineage graph.
- `dap-planner` DSL + binder for aggregate queries. Period-type validation against the
  dataset is enforced at bind time.
- `dap-runtime` scalar `aggregate_oracle` function. End-to-end tests assert
  `vectorized_result == oracle_result` for scan→filter→aggregate pipelines.

## Tests at G1 close

- 26 `dap-core` unit tests.
- 3 `dap-catalog` unit tests.
- 14 `dap-runtime` unit + 3 end-to-end integration tests.
- 3 `dap-planner` DSL-to-result integration tests.

## Known limitations carried forward

- Projection pruning is disabled (see comment in `runner.rs`) pending OPT-001.
- Period values round-trip as `Value::Str` on read because `ColumnBuffer::value_at` uses the
  physical type. A logical-type-aware projection lands with G3 completion.
