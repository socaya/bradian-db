# ADR 0215 — AVG scalar aggregate

## Status

Accepted.

## Context

ADR 0214 added `SUM`, `MIN`, `MAX` to the `AggSpec` enum but
left out `AVG` so the rounding policy could be designed
deliberately. Scalar averages are one of the most-requested
aggregations in ad-hoc queries.

## Decision

Extend `AggSpec` with `Avg(column)` and compute
`SUM(non_null) / COUNT(non_null)` using i128 arithmetic and
half-even rounding.

- Grammar: `AVG(col)` at the head of SELECT; owns the whole
  projection list like the other aggregates.
- Evaluation:
  - Iterate the filtered scan; skip `Value::Null`.
  - Accumulate the sum into `i128`; reject overflow.
  - When the non-null count is zero, return `Value::Null`.
  - Otherwise divide with `divide_round_half_even`: half-ties
    round to the nearest even integer (banker's rounding) and
    the sign of the half-step matches the sign of
    `numerator × denominator`.
- Result type:
  - `Int32` / `Int64` columns → `Value::Int64` (truncated to
    integer with half-even rounding; Int32 widens to Int64 the
    same way SUM does).
  - `Decimal` columns → `Value::Decimal` preserving the column's
    declared scale (the sum stays in the fixed-scale i128
    representation, and the divide / round operates in that
    same unit).
- Non-numeric columns rejected at evaluation time with
  `SqlError::Type`.

## Consequences

- Carries through all four engines via `evaluate_aggregate`.
- Rounding mode is documented and testable; callers who need
  truncated integer averages can compute `SUM / COUNT`
  themselves once we add `COUNT(col)`.
- Validated by `tests/base_avg.rs` (13 cases: integer average,
  half-even rounding up to even, half-even rounding down to even,
  NULL skipping, empty table, all-NULL, Decimal scale
  preservation, non-numeric rejection, unknown-column rejection,
  PK WHERE, negative half-even, Domain + MVCC parity). The 14
  SUM/MIN/MAX and 12 COUNT(*) tests still pass unchanged.
